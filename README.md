# AI Resume Analyzer & Job Matcher

Upload a PDF resume, paste a job description, and get an ATS-style report generated by an LLM on Groq's free tier. Built with Python and Streamlit.

## Features

- ATS match score (0–100)
- Matched, missing and partially matched skills
- Strengths and weaknesses
- Experience, education and project fit
- Resume improvement recommendations
- 10 interview questions tailored to the resume and job
- Optional general resume tips

## Project structure

```
AI_Resume_Analyzer/
├── app.py            # Streamlit app
├── requirements.txt
├── .env              # your Groq API key (git-ignored)
├── .gitignore
└── README.md
```

## Setup

Open a terminal in the project folder.

```bash
python -m venv venv
venv\Scripts\activate
pip install -r requirements.txt
```

On macOS or Linux, activate with `source venv/bin/activate` instead.

Get a free API key from the [Groq Console](https://console.groq.com/keys) and put it in `.env`:

```
GROQ_API_KEY=gsk_xxxxxxxxxxxxxxxxx
```

Never commit `.env` to GitHub. It is already listed in `.gitignore`.

## Run

```bash
streamlit run app.py
```

Then open http://localhost:8501, upload a text-based PDF resume, paste a job description and click **Analyze Resume**.

## How it works

```
Resume PDF --pypdf--> text ─┐
                            ├─> prompt ─> Groq LLM (strict JSON schema) ─> Streamlit report
Job description ────────────┘
```

The app asks the model for a reply that must match a fixed JSON schema (Groq [Structured Outputs](https://console.groq.com/docs/structured-outputs)), so every report has the same fields and needs no JSON clean-up.

## Model

`app.py` uses `openai/gpt-oss-120b`. Groq retired `llama-3.3-70b-versatile` for free-tier keys on 2026-08-16. If this model is retired too, change `MODEL` in `app.py` to one that supports strict JSON schema, such as `openai/gpt-oss-20b`. The free tier allows about 8K tokens per minute, so very long resumes or job descriptions may be rejected.
